# Jeramie Anne Losorata – Personal Portfolio

A personal portfolio website with a playful desktop-style interface. It shows my profile, projects, skills, certificates, achievements and a contact form. 

## Live Website
🔗 **https://julmaerlithe.github.io**

## Features
- **Home:** name, profile picture, short bio and an animated lanyard ID-card intro
- **Projects:** 7 projects, each with a description, technologies used, screenshots, documents and links
- **Contact:** a form (name, email, message) that shows a success alert on submit
- Responsive layout for mobile and desktop (Flexbox and CSS Grid)
- Smooth navigation using the bottom dock and pop-up windows
- **Dark mode** toggle that saves your preference (localStorage)
- **Latest repositories** fetched live from the GitHub API
- Hover effects, floating icons and fade-in animations

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, CSS variables, animations)
- Vanilla JavaScript (DOM, Fetch API, localStorage)
- GitHub REST API
- Google Fonts
- GitHub Pages (hosting)

## Setup Instructions
No build step or dependencies are needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/julmaerlithe/julmaerlithe.github.io.git
   ```
2. Go into the folder:
   ```bash
   cd julmaerlithe.github.io
   ```
3. Open `index.html` in your browser, or run a local server:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.
